# Devious Devil Online Manual

Japanese, Korean and English user guide for the Devious Devil outfit.

- Japanese: `index.html`
- Korean: `ko/index.html`
- English: `en/index.html`

Publish this repository using GitHub Pages: select **Deploy from a branch**, then **main / (root)** in Settings → Pages.

This repository contains only the public manual and its screenshot. Unity packages, avatar models, private drafts and credentials are not included.

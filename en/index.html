DEVIOUS DEVIL USER GUIDE

Devious Devil User Guide

Includes a breast-size gimmick that adjusts the body and outfit together. Depending on the avatar, use Devil_BreastShape or the avatar’s original breast-size menu.

The dedicated radial menu also controls sunglasses, transparency adjustments and a looping dance.

Set up the outfit

  1. Install Modular Avatar and lilToon in your VCC VRChat avatar Unity project.
  2. Import the unitypackage for your avatar.
  3. Set the body’s breast-related shape keys to 0 in advance. Reset inward-correction keys such as Breast_Inside / Breast_inside to obtain the neutral shape. Names differ between avatars.
  4. Place the outfit Prefab for your chosen color directly under the avatar root. Do not add several color versions at the same time.
  5. Open the dedicated Devious Devil menu in GestureManager or VRChat.

GestureManager is for testing in Unity; it is not required to use the outfit.

Seven color options

Every avatar version includes all seven colors listed below.

  • Pink
  • Blue
  • Lavender
  • Mint
  • Pumpkin
  • White
  • Yellow

Choose one color from the Prefab folder and place it directly under your avatar. The default Prefab without a color suffix is Pink.

Avatar notes

Yumeka

Use the avatar’s original Yumeka_Option → Breasts_Size menu. 50% is neutral. At 100%, body Big_1=75 and outfit=100. Big_2 is not animated.

Siusiu

Use Devil_BreastShape in the outfit menu. 50% is neutral; lower values make the breasts smaller and higher values make them larger.

NanaseNoir

Use the avatar’s original breast-size menu; the outfit follows it. The outfit’s Devil_BreastShape control is not used.

Chocolat

Use Devil_BreastShape in the outfit menu. 50% is neutral; lower values make the breasts smaller and higher values make them larger.

Milltina

Use Devil_BreastShape in the outfit menu. 50% is neutral. The bag has no Small shape key, so it follows Big only.

Wendy

Use the avatar’s original breast-size menu. At 100%, body Breasts_big=50 and outfit=100. Before setup, set the body’s Breasts_closer to 0. The bolero and top also have an initial Breasts_closer value of 0.

Urara

Use Devil_BreastShape in the outfit menu. 50% is neutral. The bag has no Small shape key, so it follows Big only.

Miriam

Miriam uses the dedicated Devil_BreastShape control. Breast enlarges the breasts; this avatar has no Small shape key.

Ramune

Ramune uses the avatar’s original 「バストサイズ」 menu.

Use the dedicated radial menu

Open the customization menu inside Devious Devil. Starting with Sunglasses at the upper right, clockwise, the six items are:

OrderControlHow to use it
1Toggle sunglassesSunglassesSwitches the sunglasses on or off each time you select it.
2Adjust bolero transparencyBolero TransparencyThe default is 50%. Adjust bolero transparency with reference values of 24 at 0%, 34 at 50%, and 43 at 100%.
3Reduce upper-skirt transparencyUpper Skirt TransparencyAdjusts only the upper skirt. At maximum adjustment, transparency reaches 0: fully opaque.
4Reduce lower-skirt transparencyLower Skirt TransparencyAdjusts only the lower skirt. At maximum adjustment, transparency reaches 0: fully opaque.
5Looping danceDeviousRollyTurn on to play the dedicated looping dance; turn off to stop it.
6Breast-size adjustmentDevil_BreastShapeShown on the avatars that use this control. 50% is neutral; lower values make the breasts smaller and higher values make them larger.

The bolero defaults to 50%. The upper and lower skirt controls only reduce transparency. The upper and lower skirt can each reach transparency 0, meaning opaque, not invisible. The radial percentage is the adjustment amount. Menu positions and available items may vary with the avatar and other installed menus.

Bolero transparency slider

Use Bolero Transparency in the dedicated menu. The default is 50%. Adjust toward either 0% or 100% from this midpoint.

SliderBolero adjustment valuePosition
0%24Minimum
50%34Default / reference
100%43Maximum

From 0–50%, the value changes linearly from 24 to 34. From 50–100%, it changes linearly from 34 to 43. Return the slider to 50% to restore the reference setting.

The slider percentage and the adjustment values 24, 34 and 43 are not actual light-transmission percentages. Setting the slider to 0% does not hide the bolero. The upper- and lower-skirt transparency sliders are separate controls.

Set the shape manually without the breast gimmick

To keep a fixed shape, remove the breast gimmick, then set the body and outfit shape keys manually.

The following is a general workflow. Object and FX layer names differ between avatars. The specific Eku and Shinano names below are examples.

  1. Exit Unity Play Mode. Duplicate the outfit Prefab and any FX controller you will edit as a backup.
  2. Remove the body and outfit breast-correction MA Merge Animator components from the breast-correction object. For Eku, this is DeviousDevil_BreastCorrection; for Shinano, DeviousDevil_BreastCorrection_Sinano. You may delete the entire child if it contains only breast correction. Keep the outfit root and components for other features. Remove the correction components rather than simply deactivating the child.
  3. For avatars without an original breast gimmick, proceed to manual shape settings. To remove the unused Devil_BreastShape menu item, duplicate the outfit Expressions Menu first, remove the item, and assign the duplicate to the MA setting that previously referenced the original menu.
  4. For avatars with an original breast gimmick, duplicate the avatar’s FX controller and also remove the layer control that animates breast size. See the Eku example below. Layer names differ on other avatars; do not delete layers by assuming they have the same name.
  5. First reset the body’s breast-related shape keys to 0, including inward-correction keys such as Breast_Inside / Breast_inside. Then set your preferred values under Skinned Mesh Renderer → BlendShapes on the body and outfit. Adjust the breast shape keys that actually exist on the bolero, top and bag. If breast-specific MA Blendshape Sync remains, adjust its source. Remove those breast-only sync entries as well only if you want to set each part independently.
  6. Save the outfit Prefab and scene. Check in GestureManager or VRChat that your fixed settings remain in place.

Remove breast-size control from Eku’s original FX

Duplicate the Controller assigned under Avatar Descriptor → Playable Layers → FX. Open the copy in the Animator window and remove only the Breast layer. In Eku’s original FX, the State is named BreastSize.

Assign the copied controller to the Avatar Descriptor’s FX slot. Keep all other layers and parameters. The original breast animation would otherwise overwrite your manual values.

Check when setting the shape manually

  • Removing Eku’s correction also removes the rule that holds Breast_inside at 0. Set Body_base’s Breast_inside to 0 manually if you want to use Big / Small only.
  • If another animation or MA component writes to breast shape keys, remove that breast-specific control before setting fixed values.
  • Keep the animators for sunglasses, transparency and dance.

Rename the outfit root

Distribution Prefabs with separate body and outfit animation controls allow you to add Pink or Blue to the outfit root name. Do not change internal mesh names, such as 01_Devil_Sheer Bolero, or their hierarchy.

Keep the relative-path root for the outfit’s MA Merge Animator assigned to the outfit root.

DEVIOUS DEVIL USER GUIDE

Devious Devil 取扱説明書

素体と衣装が連動する胸サイズ調整ギミックを搭載しています。アバターに応じて、専用のDevil_BreastShapeまたはアバター標準の胸メニューから操作できます。

専用ラジアルメニューで、サングラスの着脱・透明度調整・専用ループダンスも操作できます。

導入カラー（全7色）アバター別の設定シェイプキー一覧ラジアルメニューボレロの透明度羽としっぽ胸の調整胸ギミックを使わない衣装名の変更Performance

衣装を導入する

  1. VCCのVRChatアバター用Unity Projectに、Modular AvatarとlilToonを先に導入します。
  2. 使用するアバターに対応したunitypackageをインポートします。
  3. 素体のBodyにある胸関連Shape Keyをあらかじめ0にします。Breast_Inside／Breast_insideなどの内寄せ補正も0に戻し、基準の形状にしてください。Shape Keyの表記はアバターごとに異なります。
  4. パッケージのPrefabフォルダーから、使用する色の衣装Prefabをアバター直下に配置します。色違いを同時に複数配置しないでください。
  5. GestureManagerまたはVRChatで、Devious Devilの専用メニューを開きます。

GestureManagerはUnity内での動作確認用です。衣装を使用するための必須ツールではありません。

アバター別の補足

ゆめか / Yumeka

アバター標準のYumeka_Option → Breasts_Sizeを使用します。50％が中立、100％で素体Big_1＝75／衣装＝100になります。Big_2は動かしません。

Siusiu

衣装メニューのDevil_BreastShapeを使用します。50％が中立で、下げると小さく、上げると大きくなります。

ナナセノワール / NanaseNoir

アバター標準の胸サイズメニューを使用し、衣装も連動します。衣装側のDevil_BreastShapeは使用しません。

ショコラ / Chocolat

衣装メニューのDevil_BreastShapeを使用します。50％が中立で、下げると小さく、上げると大きくなります。

ミルティナ / Milltina

衣装メニューのDevil_BreastShapeを使用します。50％が中立です。バッグにはSmall用Shape Keyがないため、バッグはBigのみ連動します。

ウェンディ / Wendy

アバター標準の胸サイズメニューを使用します。100％時は素体Breasts_big＝50／衣装＝100です。導入前に素体のBreasts_closerを0にしてください。ボレロとトップのBreasts_closer初期値も0です。

うらら / Urara

衣装メニューのDevil_BreastShapeを使用します。50％が中立です。バッグにはSmall用Shape Keyがないため、バッグはBigのみ連動します。

Miriam

ミリアムは専用のDevil_BreastShapeから操作します。Breastは胸を大きくするShape Keyで、Small用Shape Keyはありません。

Ramune

ラムネはアバター標準の「バストサイズ」メニューを使用します。

専用ラジアルメニューを使う

Devious Devil内のカスタマイズメニューで操作します。画像の右上のSunglassesから時計回りに、次の6項目が並んでいます。

順項目使い方
1サングラスの着脱Sunglasses選ぶたびにサングラスの表示をON／OFFできます。
2ボレロの透明度を調整するBolero Transparency初期値は50％です。0％＝24、50％＝34、100％＝43を基準に、ボレロの透明度を調整します。
3スカート上段の透明度を下げるUpper Skirt Transparency上段だけの透明度を下げます。最大まで操作すると透明度0（透けない状態）になります。
4スカート下段の透明度を下げるLower Skirt Transparency下段だけの透明度を下げます。最大まで操作すると透明度0（透けない状態）になります。
5専用ループダンスDeviousRollyONで専用のループダンスを再生し、OFFで終了します。
6胸のサイズ調整Devil_BreastShape対応するアバターのみ表示されます。50％が中立で、下げると小さく、上げると大きくなります。

ボレロは50％が初期値です。スカートは上下段を個別に、最大で透明度0（透けない状態）まで下げられます。ラジアルの％は調整量で、透明度0は非表示を意味しません。メニュー位置や表示項目は、アバターと他のメニュー構成によって異なる場合があります。

ボレロの透明度スライダー

専用メニューの Bolero Transparency で調整します。初期値は50％です。50％を基準に、0％側・100％側の両方向へ調整できます。

スライダーボレロの調整値状態
0%24下限
50%34初期値・基準
100%43上限

0～50％は24から34へ、50～100％は34から43へ、直線的に変化します。基準状態に戻したい場合は50％に戻してください。

スライダーの％や調整値24・34・43は、実際の透過率を示すものではありません。0％でもボレロは非表示になりません。スカート上下段の透明度スライダーは別の設定です。

胸ギミックを使わず手動で設定する

好みの胸の形状を固定したい場合は、胸ギミックを外してから、素体と衣装のShape Keyを手動設定します。以下は共通の進め方です。オブジェクト名・FXのLayer名はアバターごとに異なります。エクとしなのの具体名は例として記載しています。

  1. UnityのPlay Modeを終了し、作業前の衣装Prefabと変更するFXを複製してバックアップします。
  2. 胸補正専用オブジェクトの、素体用・衣装用の胸補正MA Merge Animatorを外します。エクはDeviousDevil_BreastCorrection、しなのはDeviousDevil_BreastCorrection_Sinanoが対象です。胸補正だけを含む子オブジェクトなら、その子ごと削除できます。衣装ルートや他のギミック用Componentは残してください。子を非表示にするだけではなく、胸補正を追加するComponentを外します。
  3. 元から胸ギミックがないタイプは、そのまま手動設定に進みます。使用しないDevil_BreastShapeのメニュー項目は、衣装側Expressions Menuを複製してから削除できます。複製したメニューを、元のメニューを参照していたMA設定へ割り当てます。
  4. 標準の胸ギミックがあるタイプは、アバター側FXを複製し、胸サイズを動かすLayerの制御も外します。エクの具体例は下記を参照してください。他のアバターではLayer名が異なるため、同じ名前で探して削除しないでください。
  5. 素体のBodyの胸関連Shape Keyを、Breast_Inside／Breast_insideなども含めてまず0に戻します。その後、素体と衣装のSkinned Mesh Renderer → BlendShapesで好みの値を設定します。ボレロ・トップ・バッグは、存在する胸用Shape Keyを調整します。胸用MA Blendshape Syncが残っている場合は連動元から調整し、各パーツを別々に設定する場合だけ胸用の同期項目も外してください。
  6. 衣装Prefabとシーンを保存し、GestureManagerまたはVRChatで固定値が維持されることを確認します。

エクの標準FXから胸サイズ制御を外す

Avatar DescriptorのPlayable Layers → FXに割り当てられたControllerを複製します。複製したFXをAnimatorウィンドウで開き、Breast Layerだけを削除します。エクの標準FXでは、State名はBreastSizeです。

複製したControllerをAvatar DescriptorのFXへ割り当てます。他のLayerとParameterは維持してください。元のFXのままでは、標準BreastメニューのAnimationが手動値を上書きします。

手動設定時に確認すること

  • エクの胸補正を外すとBreast_insideの0固定も外れます。Big／Smallだけで設定したい場合は、Body_baseのBreast_insideを手動で0にします。
  • 別のMA Blendshape SyncやAnimationが胸へ書き込む構成では、その胸の制御も外してから設定します。
  • サングラス・透明度・ダンス用のAnimatorは外さないでください。

衣装ルートの名前を変更する

素体用と衣装用を分けた配布Prefabでは、衣装ルート名にPinkやBlueを付けられます。内部のメッシュ名（01_Devil_Sheer Boleroなど）と階層は変更しないでください。

衣装用MA Merge Animatorの相対パスのルートは、衣装ルートを指定したままにします。
